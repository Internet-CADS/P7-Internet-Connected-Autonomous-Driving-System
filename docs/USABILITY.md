# Monitoring study

Recruit approximately five participants. For each session, use the same completed perturbed run and one other run in the monitor. Record an anonymous participant number, whether each task was completed without help, time in seconds, and one observation about any difficulty.

1. **Find a run.** Select the model, episode seed and perturbation the facilitator names. Success means the selected run matches all three.
2. **Read the policy decision.** Go to the step the facilitator names. Report the action that was applied and whether the clean observation would have produced a different action. Compare the answers with the run's exported log.
3. **Inspect the perturbation.** Find the displayed budget and measured L∞ magnitude, then identify one observation feature that changed. Compare the answers with that step in the log.
4. **Return to the most recent step.** Navigate to an earlier step, then show the latest step again. Success means the step counter is back at the end of the run.

Start timing after the facilitator finishes reading the task. Stop when the participant gives a final answer, gives up, or reaches two minutes. Keep failures in the completion-rate denominator. Summarize completion rate and median completion time by task, and describe the recurring problems. Include SUS if the course confirms it.
